## Project Overview
This project analyzes crowdfunding campaign data to identify factors influencing campaign success and funding performance.

## Tools Used
- Excel
- MySQL
- Power BI
- Tableau
- Power query

## Key KPIs
- Total Campaigns
- Successful Campaigns
- Success Rate
- Total Funds Raised
- Average Funding Amount

## Analysis Performed
- Category-wise campaign performance
- Country-wise funding analysis
- Successful vs Failed campaigns
- Funding trends over time
- Top performing categories

## Skills Demonstrated
- Data Cleaning
- SQL Querying
- Data Visualization
- KPI Reporting
- Business Analysis
